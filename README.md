# Pocket - Vue.js Blog Application

A professional, modern blog application built with Vue 3, featuring a beautiful pink and white color scheme with dark mode support.

## Features

- 🔐 User Authentication (Register/Login)
- 📝 Create, Read, Update, Delete Blog Posts
- 💬 Comment System
- 👍 Like and Dislike Posts
- 🔥 Trending Posts Section
- ⭐ New Posts Section
- 🌓 Dark Mode Toggle
- 🎨 Professional UI with Pink & White Theme
- 📱 Responsive Design
- 🔒 Role-based Access Control (Admin features)
- 📍 Collapsible Left Sidebar Navigation

## Tech Stack

- **Vue 3** - Progressive JavaScript Framework
- **Vue Router** - Official router for Vue.js
- **Pinia** - State management
- **Axios** - HTTP client
- **Bootstrap Icons** - Icon library
- **Notyf** - Toast notifications
- **Vite** - Build tool
- **Inter Font Family** - Professional typography

## Color Scheme

### Light Mode
- Primary Background: White (#ffffff)
- Secondary Background: Light Pink (#fff5f9)
- Accent: Hot Pink (#ff69b4)

### Dark Mode
- Primary Background: Dark Gray (#1a1a1a)
- Secondary Background: Dark Pink (#2d1a26)
- Accent: Hot Pink (#ff69b4)
